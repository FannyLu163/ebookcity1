# 明日書城 PHP 版操作說明書

本文件說明明日書城 PHP 版網站的前台瀏覽、後台管理、圖片上傳、常見錯誤處理與日常維護方式。

## 1. 系統網址與啟動

本機測試網址：

```text
http://localhost:8080
```

啟動本機網站：

```powershell
cd "C:\Users\lsf11\Documents\New project\php-ebookcity"
C:\xampp\php\php.exe -S localhost:8080 -t public
```

若已經有伺服器在執行，重新整理瀏覽器即可。若頁面無法開啟，請確認啟動視窗沒有關閉。

## 2. 前台操作

### 2.1 首頁書籍列表

首頁會顯示書籍卡片，包含封面、書名、副標題、出版日期、作者、分類與簡介。

可進行的操作：

- 點書名或封面：進入書籍詳細頁。
- 點作者名稱：進入作者介紹頁。
- 點分類或選單分類：篩選該分類書籍。
- 使用上方搜尋框：依書名、作者、ISBN 等關鍵字搜尋。
- 使用下方分頁：切換上一頁、下一頁或指定頁碼。

### 2.2 書籍詳細頁

書籍詳細頁會顯示：

- 書籍封面
- 書名與副標題
- 作者連結
- ISBN、出版日期等資料
- 分類標籤
- 內容簡介
- 作者簡介
- 目錄
- 試閱內容

作者名稱若已建立關聯，會連到作者介紹頁。

### 2.3 作者專區

作者專區網址：

```text
http://localhost:8080/authors.php
```

可進行的操作：

- 搜尋作者名稱或簡介。
- 點作者名稱或圖片：進入作者介紹頁。
- 使用分頁瀏覽作者列表。

作者介紹頁會顯示作者簡介、作者的話、網站連結，以及該作者的作品列表。

## 3. 後台登入

後台登入網址：

```text
http://localhost:8080/admin/login.php
```

預設登入帳號與密碼由 `.env` 設定：

```text
ADMIN_USER
ADMIN_PASS
```

若沒有設定 `.env`，程式會使用預設值。正式使用時請務必改成自訂帳密。

登入後可使用：

- 後台首頁
- 書籍管理
- 作者管理
- 前台
- 登出

## 4. 後台首頁

後台首頁會顯示統計：

- 全部書籍
- 前台顯示書籍
- 作者

若資料庫無法連線，後台首頁會顯示資料庫錯誤提示，統計可能暫時為 0。這不代表資料消失，通常是資料庫連線、ODBC Driver、Azure SQL 狀態或網路設定問題。

## 5. 書籍管理

書籍管理網址：

```text
http://localhost:8080/admin/books.php
```

可進行的操作：

- 搜尋書籍。
- 查看書籍列表。
- 點「編輯」進入書籍編輯頁。
- 點「新增書籍」建立新書籍。

## 6. 編輯書籍

書籍編輯頁包含以下欄位：

- 書名
- 副標題
- 出版日期
- ISBN
- 書號
- 主分類
- 分類
- 關聯作者
- 新增作者
- 前台顯示
- 圖片路徑
- 圖片上傳
- 縮圖路徑
- 縮圖上傳
- 簡介
- 目錄
- 試閱說明

### 6.1 欄位限制

| 欄位 | 限制 |
| --- | --- |
| 書名 | 最多 50 個字 |
| 副標題 | 最多 100 個字 |
| ISBN | 最多 20 個字 |
| 書號 | 最多 20 個字 |
| 圖片路徑 | 最多 255 個字 |
| 縮圖路徑 | 最多 255 個字 |
| 試閱說明 | 最多 500 個字 |

若欄位不符合規格，錯誤訊息會顯示在欄位旁邊，頁面會自動移到第一個錯誤欄位。

### 6.2 分類選擇

書籍分類分為：

- 主分類
- 分類

請先選主分類，再選下方對應分類。

### 6.3 關聯作者

操作方式：

1. 在「關聯作者」輸入作者關鍵字。
2. 從下拉選單選擇作者。
3. 點「加入」。
4. 作者會顯示為標籤。
5. 若要移除，點作者標籤旁的關閉按鈕。

若作者不存在，可以使用「新增作者」輸入新作者名稱。儲存後系統會建立作者資料並關聯到該書。

若輸入的新增作者名稱已存在，系統會優先關聯既有作者，避免建立重複資料。

### 6.4 圖片上傳

圖片上傳後會存到：

```text
/imgs/pro/
```

系統會自動改檔名避免重複。

主圖限制：

- 尺寸：500x500 以內
- 檔案大小：1MB 以內
- 格式：jpg、png、gif、webp

縮圖限制：

- 尺寸：250x250 以內
- 檔案大小：500KB 以內
- 格式：jpg、png、gif、webp

重新選擇圖片時，系統會立即清除舊錯誤提示，並在前端即時檢查格式、大小與尺寸。若不符合規格，不需要按儲存就會看到錯誤。

### 6.5 簡介 HTML 編輯器

簡介欄位支援 HTML 內容，提供工具列：

- 粗體
- 斜體
- 底線
- 段落
- 標題
- 清單
- 編號
- 連結
- 清除格式
- 字型選擇

此欄位會在前台書籍頁直接渲染。

### 6.6 編輯頁操作按鈕

頁面底部提供：

- 儲存：儲存目前書籍資料。
- 查看前台：開新視窗查看該書前台頁。

右下角浮動按鈕：

- ↑：返回頁面最上方。

操作者在任何段落都可以點右下角按鈕回到上方。

## 7. 作者管理

作者管理網址：

```text
http://localhost:8080/admin/authors.php
```

可進行的操作：

- 搜尋作者。
- 查看作者列表。
- 點「編輯」進入作者編輯頁。

## 8. 編輯作者

作者編輯頁包含以下欄位：

- 作者筆名
- Slug
- 個人網站
- 第二網站
- 頭像路徑
- 照片路徑
- 排序
- 推薦作者
- 前台顯示
- 作者簡介
- 作者的話

操作完成後點「儲存」。

Slug 會用於作者介紹頁網址。若手動修改，請避免與其他作者重複。

## 9. 常見錯誤與處理

### 9.1 後台統計變成 0

可能原因：

- 資料庫暫時無法連線。
- Azure SQL 暫時不可用。
- ODBC Driver 或 PHP SQL Server driver 異常。
- 本機 PHP server 沒有使用完整網路權限啟動。

處理方式：

1. 重新整理後台首頁。
2. 確認 `localhost:8080` 的 PHP server 仍在執行。
3. 重新啟動 PHP server。
4. 檢查後台首頁顯示的資料庫錯誤訊息。

### 9.2 圖片尺寸錯誤

主圖必須在 500x500 以內，縮圖必須在 250x250 以內。

若出現錯誤，請重新選擇符合規格的圖片。重新選圖時紅框會自動清除並重新檢查。

### 9.3 新增作者出現重複資料錯誤

系統目前會優先重用同名作者，並避免重複的 `legacy_blog_id` 與 slug。

若仍出現錯誤，請確認：

- 是否已存在同名作者。
- 是否手動輸入了重複 slug。
- 是否可改用「關聯作者」選擇既有作者。

### 9.4 首頁作者沒有連結

若書籍已建立作者關聯，首頁列表作者會連到作者介紹頁。

若只顯示純文字，通常代表該書只有產品表中的作者文字，尚未建立作者關聯。請到後台編輯書籍，使用「關聯作者」加入作者。

## 10. 日常維護建議

- 新增或修改資料後，請到前台確認顯示是否正確。
- 上傳圖片前先確認尺寸與檔案大小。
- 作者資料應盡量使用「關聯作者」，避免只填文字。
- 重要修改完成後請提交 Git 並推送到 GitHub。
- 不要把 `.env` 或含密碼的設定檔提交到 GitHub。

## 11. GitHub 更新流程

查看修改狀態：

```powershell
git status --short
```

提交修改：

```powershell
git add 檔案路徑
git commit -m "說明本次修改"
```

推送到 GitHub：

```powershell
git push origin main
```
